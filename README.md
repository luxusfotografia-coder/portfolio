# Portfolio — Belén Caamaño

Sitio personal. Marketing y comunicación en la industria de la salud,
y Luxus Fotografía, marca propia de fotografía de eventos.

Publicado con GitHub Pages: https://USUARIO.github.io/portfolio/

## Estructura
- `index.html` — el sitio entero, sin dependencias externas
- `assets/img/web/` — imágenes optimizadas para web
- `assets/fonts/` — Inter y Playfair Display, servidas localmente

No usa build ni framework: se edita el HTML y se sube.
